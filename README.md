## Featured project

### [TrafficLens](https://github.com/nabilety008/TrafficLens)

A lightweight, real-time network traffic monitor built specifically for Windows.

- Real-time download and upload monitoring
- Per-application traffic usage
- Active TCP/UDP connections
- Traffic history with charts and CSV export
- Configurable traffic alerts
- Floating network widget and system tray integration
- English and Persian (RTL) user interface

Monitoring is fully local — no account, no cloud service, and packet payload
contents are never captured.
